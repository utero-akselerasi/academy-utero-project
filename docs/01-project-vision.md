# Project Vision

## Nama Internal

Utero Academy Platform (UAP)

## Ringkasan

UAP adalah Education Management System yang menyatukan website publik, headless CMS, LKP management, learning management, internship management, task management, absensi, daily report, school portal, mentor portal, admin portal, dan sertifikasi.

Platform ini tidak hanya menggantikan website WordPress, tetapi menjadi pusat operasional digital Utero Academy.

## Tujuan Utama

1. Menyediakan website publik yang dikelola dari CMS internal.
2. Mengelola lifecycle peserta magang dari pendaftaran sampai alumni.
3. Mengelola program LKP, kurikulum, batch, kelas, jadwal, instruktur, dan sertifikat.
4. Menyediakan LMS untuk course, materi, quiz, assignment, progress, dan certificate.
5. Menyediakan dashboard berbeda untuk Super Admin, Admin, Mentor, Sekolah, dan Peserta Magang.
6. Menyediakan data terstruktur untuk absensi, task, daily report, assessment, dan sertifikasi.
7. Menyiapkan CMS yang reusable untuk website lain milik Utero.

## Role Awal

1. Super Admin
2. Admin Academy
3. Mentor
4. Sekolah atau Kampus
5. Peserta Magang
6. Visitor

## Prinsip Produk

- Satu login untuk semua dashboard.
- Role menentukan akses halaman, data, dan aksi.
- Setiap proses penting punya status yang eksplisit.
- Setiap approval dan revisi harus meninggalkan jejak audit.
- CMS dibuat headless agar bisa melayani lebih dari satu frontend.
- Struktur database harus stabil, mudah dikembangkan, dan siap untuk laporan manajemen.
